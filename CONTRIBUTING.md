# Contribution guidelines

Thanks for helping keep this list useful. Please read this before opening a pull request.

## What gets listed

An entry is accepted when all of these are true:

1. **It is live.** The link loads and the product works today.
2. **It supports Hyperliquid, on its own pages.** The product's own site, docs, repository or app-store listing says
   it works with Hyperliquid (HIP-3 markets or the deployers behind them). Third-party mentions are not enough.
3. **It is active.** A release, changelog entry, commit, app update or announcement in the last 6 months.
4. **It is useful to Hyperliquid users or builders.** Personal vaults, single wallets, tokens, signal groups,
   referral pages and affiliate links are not listed.
5. **It is not misleading.** Products that promise returns, show unverified performance figures as a selling point,
   or have scam signals are not listed.

Open-source repositories also need a license and a README that explains what the code does.

## How to add an entry

- One entry per pull request. Use a title like `Add <Name> to <Section>`.
- Add it in alphabetical order inside the right section.
- Use this format:

  ```
  - [Name](https://official-url) - Short neutral description.
  ```

- The description is one sentence, about 15 words or fewer, and ends with a period.
- Write what the product does. No "best", "leading", "#1", no profit or APY claims, no emojis.
- Remove referral and tracking parameters (`?ref=`, `?referral=`, `utm_*`) from links.
- In the pull request, add the link to the page on the product's own site that shows Hyperliquid support.

## Changes and removals

Open a pull request or an issue if a link is dead, a product has shut down or stopped supporting Hyperliquid,
or a description is wrong. Please include the source.

## Review

The maintainers check every addition against the rules above, usually within a week. Entries can be removed if they
stop meeting the rules. The list is fully reviewed once a month.
